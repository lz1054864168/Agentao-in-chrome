# Agentao in Chrome v3.0.0 — 开箱即用安装指南

> 本文件夹是完整可运行的发布包：**Chrome 扩展 + 已打包的本地原生宿主**。
> 原生宿主（`agentao-chrome-host.exe`）由 PyInstaller 冻结，内置 Agentao 运行时 **0.5.11** 及全部依赖——**无需安装 Python 或 agentao**。

## 包内结构

```
extension/                          # ← 整个文件夹既是扩展，也是安装根
├── manifest.json                   # Chrome MV3 清单（版本 3.0.0）
├── sidepanel.html / .js / .css     # 侧边栏聊天界面
├── options.html / .js / .css       # 设置页
├── ...
├── 安装说明.md                     # 本文件
└── native-host/                    # 内置原生宿主
    ├── agentao-chrome-host.exe     # 冻结宿主（内置 Agentao 0.5.11）
    └── install.bat                 # 双击安装
```

## 一、加载扩展（约 30 秒）

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车。
2. 打开右上角**开发者模式**开关。
3. 点击左上角**加载已解压的扩展程序**，选择本文件夹（`extension`）。
4. 工具栏出现 Agentao 图标即加载成功（扩展 ID 固定为
   `oceidmjneaojejdaonljejgpgjlafbpo`，由 manifest.json 的 `key` 字段锁定）。

## 二、安装原生宿主（双击即可，无需命令行）

1. 进入本文件夹下的 `native-host` 子目录。
2. 双击 **install.bat**。
   - 脚本会为本机当前用户注册 Chrome 原生消息宿主
     （`com.agentao.chrome_extension`），并写入默认工作目录
     `~/.agentao-chrome/workspace`。同一清单会注册到本机所有
     Chromium 系浏览器（Chrome / Edge / Brave / Chromium / Vivaldi）。
3. 如需指定扩展 ID，可用命令行：

   ```bat
   agentao-chrome-host.exe --install --extension-id <你的扩展ID>
   ```

   默认 ID 即上述固定 ID，通常无需指定。

## 三、开始使用

1. 点击工具栏 Agentao 图标（或快捷键 `Ctrl+E`）打开侧边栏。
2. 首次使用点击侧边栏设置，填入模型供应商的 API Key、Base URL 与模型名。
3. 侧边栏顶栏显示**已连接**即宿主通信正常，可直接对话。

## 常见问题

| 问题 | 处理 |
|------|------|
| 顶栏显示「未连接」 | 确认已执行第二步 install.bat；重启 Chrome 后重试 |
| 权限模式 | 默认 `workspace-write`（可读写工作目录）；可在设置中切换 `read-only` / `full-access` / `plan` |
| 查看日志 | `~/.agentao-chrome/logs/host.log` |
| 卸载宿主 | 删除注册表 `HKCU\Software\Google\Chrome\NativeMessagingHosts\com.agentao.chrome_extension`（其指向的 JSON 清单一并删除），再删除本文件夹 |

## 源码与构建

- 完整源码位于本发布包所在 `Releases/` 目录的同级源码根目录（`Releases/` 的上一级），或项目 GitHub 仓库。
- 原生宿主由 PyInstaller 冻结（`scripts/build_native_host.py`），
  内置 Agentao 运行时版本 0.5.11。
- 重新打包：

  ```bash
  pip install "agentao>=0.4.18" "pyinstaller>=6.0"
  python scripts/build_native_host.py --clean
  # 产物在 Releases/dist/agentao-chrome-host/
  ```
